# 桌面端界面规范 v1

主窗口和首次引导都照这份规范写。控件的样式在 `src/renderer/shared/window.css`，尺寸、字号、圆角、动效的 token 在 `src/renderer/shared/tokens.css`，颜色只从主题来（`src/themes`）。悬浮条有自己的形状，不套这份规范。

规范由测试守着，能用命令查的才算数：

| 门禁 | 测试 | 查什么 |
| --- | --- | --- |
| 文案词表 | `test/i18n/copy-lexicon.test.mjs` | 中文词条里出现"不再使用"的说法就失败（口语那几条命令行 `cli.*` 暂不在内；识别方式、步骤的旧叫法哪里都不许有） |
| 尺寸 token | `test/renderer/shared/control-sizes.test.mjs` | 控件的高度只用 `--control-*`，圆角只用 `--radius-*`，例外写明缘由；按钮一类的圆角只能是全圆 |
| 字号字重 | `test/renderer/shared/type-scale.test.mjs` | 字号只用六档、字重只用三档 |
| 颜色 | `test/themes/css-tokens.test.mjs` | 样式里不写死颜色，用到的变量都有出处 |

## 1. 文案

- **书面语**：不用口语（能用、用这个、填、挑、只看、交给、一步）。
- **不写整句**：按钮是动词或动宾，状态是名词或形容词短语，说明是名词短语，多项用" · "隔开，不带句末标点。
- **长度**：按钮、状态 2–4 个字；口径、出处放进悬停提示。
- **只留必要的字**（2026-10-22 定的）：不写"大字一行、小字一行"的说明，名字、状态、数、要用户做的事之外不加解释；设置项的名字已经在栏名里交代了的就缩短。隐私相关的事实（存在哪、发给谁）照写。
- **数值**：数和单位之间空一格（0.9 秒、850 MB）；币种紧贴数字（¥0.8）；同一列的小数位一致。
- **提示**：操作结果写成"已 + 动词"（已启用、已切换至、密钥已保存）；失败写清对象和原因。

| 场景 | 规范写法 | 不再使用 |
| --- | --- | --- |
| 按钮 | 启用 · 检测 · 下载 · 配置密钥 · 更换 · 保存 · 取消 | 使用 · 用这个 · 检查 · 填 X Key |
| 状态 | 使用中 · 已选定 · 检测通过 · 检测失败 · 检测中 · 未配置 | 能用 · 不能用 · 已选 · 已填 · 未填 |
| 标题 | 引擎 · 识别方式 · 步骤 · 厂商 · 型号 · 渠道 · 密钥 | 用法 · 挑模型 · 经由 · Key · 环节 |
| 识别方式 | 直出 · 混合 · 离线 | 原生识别 · 转写 + 润色 · 数据隐私 |
| 步骤 | 直出 · 转文字 · 整理 | 原生 · 转写 · 润色 · 第一跳 · 第二跳 · 成稿 |
| 标签 | 默认 · 已评测 · 已知问题 · 未验证 | 实测 · 未实测 · 适合 Apple 芯片 |
| 筛选 | 仅显示可用 | 只看能用的 |
| 提示 | 已切换至混合 · 密钥已保存 · 新增 22 个可用模型 | 已切到 · 解锁 22 个模型 |

标签只按事实打：跑过成批真实录音评测的打"已评测"，有已知问题的打"已知问题"（悬停看是什么），出厂默认的打"默认"。只跑通、没评测的不打标签；跑不通的不上架。照官方文档接入、还没拿真 key 调过的打"未验证"，跟着渠道走（同一个模型换一家卖可能就验过了），调通后摘掉。

## 2. 尺寸

- **控件高度三档**：`--control-sm` 28（胶囊、徽标、分段里的项、缩放条）· `--control-md` 32（按钮、输入框、分段控件）· `--control-lg` 40（搜索框、标题行的胶囊按钮）。同一行的控件同一档，字的长短不会把它们撑得参差。
- **圆角四档**：`--radius-control` 8（输入框等控件）· `--radius-block` 12（区块）· `--radius-card` 16（卡片）· `--radius-full`（胶囊：按钮一类的全用它）。
- **字号六档、字重三档**：见 `tokens.css`（源在 `src/design/app.mjs`）。
- **定宽格**：检测、操作两格各 6rem（`--col-status`、`--col-action`），控件撑满格子；引擎页的详情、推荐组合照这两格对齐；密钥面板的状态跟在名字后面（抽屉窄，说明要整行宽），只对齐操作那一格。

## 3. 按钮

- **外形一律是胶囊**：按钮、图标按钮、下拉框、标题行的胶囊按钮、状态框、检测、徽标、分段控件都是全圆，不写圆角矩形。按钮、下拉框、胶囊按钮共用 `shared/window.css` 里一条 `:where(.button, .select, .picker-trigger)`，照苹果的做法：无描边、不浮起，一层淡灰底（`--fill-selected`）、字加粗，悬停时深一点（`--fill-strong`）。新加按钮一类的东西照这个外形，测试守着圆角。
- 四种：主要（`.button.primary`，实色的主题色，不用渐变、不发光）· 次要（`.button`，默认，就是上面的胶囊）· 幽灵（`.button.ghost`，没有面，取消、收起）· 小号（`.button.small`，28 高）。撑满所在格子加 `.block`；字比格子长时（英文、"下载 253 MB"）按字撑宽，不溢出。
- 主要按钮每个区域至多一个，用于保存、确认；详情、推荐组合、密钥面板的行内一律用次要按钮。
- 按钮必须有底色或描边，不拿纯文字当按钮（链接除外）。按钮里不放箭头（开始、继续、前往、返回都一样）：渐变加光晕、带箭头的胶囊一眼就是"AI 做的"（2026-10-23 改）。
- `window.css` 先用 `:where(button)` 去掉浏览器自带的按钮外观：哪个按钮的样式漏了，退回的是一段平的字，不会冒出灰色的系统按钮（有测试守着）。
- 不可点的状态（使用中、已选定）用状态框 `.state-box`，和按钮同高同圆角、占同一个位置。
- 不可用的按钮置灰保留，悬停说明原因，不隐藏。同一时间只发一件要等主进程回话的事，这时别的启用、下载、保存都置灰，不让点了没反应。
- 图标直接放在字前面，不加"圆圈里放一个图标"的底座（品牌图标的方形底座 `.logo-tile` 除外）；单选用小号的单选标记。
- 说明性的图标也不垫彩色、渐变的方块，列表里每一项前面不放同一个装饰图标：这两样一眼就是"AI 做的"。分层靠字号、字重、细线，状态用字的颜色和小圆点说（词典页、引擎页的步骤节点照这条改过）。

## 4. 状态与检测

- 一套检测，模型、密钥两处共用，顺序固定：检测（`.check`）→ 检测中 → 检测通过 / 检测失败（`.badge`）。
- 结论用徽标：图标加淡底同色字，撑满状态列；通过只写结论，不附原文、耗时。结果徽标本身是按钮，悬停显示"重新检测"。
- 原因用说明框 `.callout`：在那一行下面，粗体结论加对象和原因，原始报错用等宽字。
- 标签 `.tag` 只有几种语气：默认（`accent`）· 已评测（`ok`）· 已知问题（`problem`）· 未验证（不加语气，灰底）；做法标签（Metal 版、CPU 版）用描边（`outline`）。

## 5. 选择控件

- **分段控件** `.segmented` / `.segment`：二到四个互斥的选项（首页的时段、引擎页的渠道），胶囊形的槽，选中项是浮起的胶囊滑块；只有一个选项时外形不变、不能点。
- **开关** `.switch`：布尔设置，整行左边是文字。
- **下拉框** `.select`：设置里的单选（主题、语言……）。外形是胶囊，右边一个箭头；用 `appearance: base-select` 画，打开后是锚在下面的玻璃单子，选中的那项右边一个主题色的勾，Mac、Windows 一个样子。选项由 `shared/dom.mjs` 的 `fillSelect` 填（里面的按钮和箭头一起放进去）。
- **录键控件**（`shared/hotkey-editor.mjs`、`hotkey-editor.css`，设置页用）：动作目录里每个动作一行，左边名字，右边每个组合一个胶囊框，框里一组键帽、键与键之间不加"+"。点框就是重录它：框亮一圈主题色、呼吸，键帽跟着实时按住的键变，下面一行写规矩（"两键以内 · esc 取消"）；松开即存，被拒时框和下面那行转成问题色、说原因，人直接重按。框右边的 × 删掉这个组合（只剩一个、又不能留空的动作不给删）；行尾"添加另一个"（至多 4 个，满了置灰并在悬停里说上限；取消只认一个键，不给加），和默认不一样时多一个"恢复默认"。点别处、换页、窗口失焦都算不录了；录着时点另一个组合或"添加另一个"直接开始新的一次。录不了（按键监听没在跑、Mac 上没给输入监控）时点了照样有反应：那一行下面说为什么。被环境变量盖着的那一行只看不改（没有 ×、添加、恢复默认），下面写删掉哪个环境变量才能改。存好、出错、装不上退回默认，都写在那一行下面，不弹窗。重画后键盘焦点留在原来那个按钮上。
- **单选**：几个平级的大选项（引擎页的识别方式），整块可点，选中的实底、描主题色边，左边一个小号的单选标记（`.radio-mark`）。
- **胶囊按钮** `.picker-trigger`：标题行右边的入口。图标或状态小圆点（首页的识别方式：齐了绿、还差什么红）、字（可以先一段淡的说明）、箭头或计数；点开浮层的箭头朝下，跳到别的页面的朝右（首页的识别方式）。
- **浮层选单**：胶囊按钮点开，是锚在按钮下面的玻璃浮层（原生 `popover`，点外面、按 Esc 收起）。每一项写清它是什么、正在用什么、还差什么。
- **推荐组合**：引擎页标题行右边的浮层选单，一项一行：左边名字和识别方式、一路经过的模型，还差的写在下面、都齐了的给整套检测；右边是月成本和启用（缺密钥给"配置密钥"，没下载给"下载"）。正在用的那项实底、描主题色边，其余平铺、细线分开。成本统一写"每天 100 次"的月成本，到分，中文写人民币、英文写美元。

## 6. 引擎页：树、画布、详情

识别方式、它用的模型、模型的详情放在一页（侧栏"引擎"，`src/renderer/hub/engine/`），一级只放名字和一个状态，细节点开才有，配置项不和浏览混在一起。

- **树**：从左往右四列，识别方式（直出、混合、离线）→ 步骤（直出、转文字、整理）→ 厂商 → 型号，每列上面一行小字写这一列是什么。识别方式三选一，点一下当场换上，还差的照实写在那一项下面；首页只显示正在用哪一种，点一下跳到这里。
- **一级只放一个状态**：步骤写选定的型号；厂商写使用中、已选定、未配置密钥、已下载 n/m 或卖它的渠道；型号写标签，右边是"使用中"或"已选定"，没下载、下载中、缺密钥只放一个小图标。缺密钥的厂商和型号颜色变淡。
- **线**：从父节点右边连到子节点左边，两头水平。正在用的那一路主题色，线上一小段光往右走；已选定、所在识别方式没在用的是虚线；其余淡线。识别方式的先后照连线排，线不交叉（有测试守着）。
- **画布**：树按舒展的间距排开，整体按比例放进窗口，可以拖动（移动超过 4 像素才算拖）、触控板捏合或按住 ⌘ / Ctrl 滚动缩放。不要网格背景、不要外框，左右和下面铺到窗口边。右下角是缩放条，左下角是图例。
- **详情**：点型号出来，停在画布右边、不跟着缩放，树平移过去让这个型号挨着它，中间一条水平的线。里面依次是标签、"启用即切换至…"（不在正在用的方式里时）、渠道、价格或规格（同组最佳标绿、评分带条）、数据发到哪、还差什么和去补的按钮、检测和主操作、许可和出处、删除。
- **密钥**：不进树，标题行右边"密钥 n/m"，点开从窗口右边滑出面板。每家一行：覆盖哪些步骤、状态、配置或更换；展开后是输入框、保存、获取密钥，已配置的还有删除和检测。从详情里点"配置密钥"来的，存好就收起面板回到详情。
- **搜索**：结果列在搜索框下面，上下键挑、回车选，选一个就沿树展开到它并打开详情。
- **宽度**：中文在默认窗口约 83%、最窄窗口约 74%（英文的字长一些，再小一点），整棵树都放得下；内容区不出现滚动条。英文长的说明不截断，只有出错原因这种长句截断、悬停看全。

## 7. 数据图：首页的热力图、花费卡

数比字多的地方画成图，不堆表格（`src/renderer/hub/home.mjs`、`spend.mjs`）。

- **只用 primary 一种颜色，分深浅**：热力图越多越浓；花费卡里柱子是浅的底纹（primary 和底色混成的实色），趋势线是实的主角。不按型号配一组彩色：型号靠图标和名字认，想看某个型号，指着它那一行，柱子里它那一份加深、其余更淡。
- **花费卡**：上面是这段时间花了多少和选时段；中间是柱子，今天按钟头、本月按天排满整月、累计按用了多久（三个月内按天、两年内按周、再久按月，`src/usage/series.mjs`）；下面每个型号一行，名字下面一道细线是占几成，几行加起来正好铺满。
- **柱子**：细、顶上圆角、贴底那头方的；没花钱的那一格是贴底的一小截，还没到的更淡。不画纵轴，只在最高那根上面写它是多少；横轴写四五个刻度，头一个靠左、最后一个靠右。
- **趋势线**：柱子上叠一条主题色的平滑实线（2 像素，下面垫一道底色的边），末端一个小圆点是"现在"，柱子密了也看得出起伏；开始花钱之前的那一段不画（今天的凌晨），从花钱的前一格起笔。灰色半透明的线压在柱子上像噪点，试过不用。到现在为止的每一格先按高斯核平滑（宽窄是格子数的 1/32、至少 0.75 格：太宽了起伏看不出来），再用单调三次曲线连起来，不冲过头、不画到 0 以下（`hub/trend.mjs`）；指着型号时换成它自己的走势。
- **细数藏起来**：指着柱子，那一根变实色，旁边浮出那一格花了多少、各型号各多少（玻璃小卡，数在前）；指着型号，那一行露出 token、次数、耗时。整段的次数、token 写在卡片最下面一行小字里。

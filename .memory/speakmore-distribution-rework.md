**2026-10-20 全部做完**：0.11.0 发布（三件事都在里面），两台电脑端到端和线上地址都验过，用户两台电脑都升到了 0.11.0（Mac 的 App 是按块更新上去的：下 1.4 MB、其余 313 MB 取自本机），README 测速图和官网换成魔搭实测，按小时封顶已生效；之后照用户定的先后撤了旧的：模型桶和四个模型、老模型 CDN 域名、解析、证书，下载地址上 0.11.0 以前的版本和 latest（CDN 缓存也刷了）。验证记录在 docs/development.md 的“验证到哪一步”。还没做的：Electron fuses（注意命令行靠 ELECTRON_RUN_AS_NODE 跑，RunAsNode 不能关），签了名的正式包之间在 App 里点更新要等 0.11.1 才能验。

当初 2026-10-20 查流量费时定的。查到的情况：流量的大头是本机模型下载（默认模型一个约 0.8 GB），其次是首次安装，更新占得少；没有被刷的迹象，但防线只有"每天封顶"，被刷就是全天 404。具体数字不记（仓库公开，`npm run stats` 能重算）。

要做的三件事，按这个顺序：
1. **模型的国内源换成魔搭（ModelScope）**，加断点续传（原来断了就删掉 .part 从头下）。用户开账号、给令牌，上传脚本、下载源、续传由 agent 来改。
2. **安装包换压缩格式并瘦身**：终端包 gzip 换 xz 实测小三成多；Electron 的语言包只留中英；开发用的包不进安装包；dmg 换 lzma。
3. **按内容寻址的分块差量更新**：文件按内容切块、块按 sha256 存一份，每个版本一张清单，更新只下本机缺的块，Mac 拼完照旧验签名和开发者。不做手工分层、不做版本间差量包（那两种是补丁）。先验证 desync 能不能拿已装目录当种子，不行再用 Node 自己写。
另外：发布包域名的封顶从每天改成按小时、到点自动恢复（用户 10-20 说"没问题"），命令交给用户跑。

用户定的约束：
- **老的模型 CDN 在魔搭端到端实测通过之前不能下线**："可以短路一会，但不能长"。
- 重构要做干净，见 [[refactor-surgical-clean]]。
- **完成标准**：在用户那台 Mac 和游戏电脑（Windows）上都端到端验过；换模型源后重新测速；把所有提到旧做法的文档都改掉。用户说会一步步指引。
- **撤旧的先后（10-19 用户再三强调，别搞混，否则宕机太久）**：两台端到端验过 → 打包发版 → 官网和 README 更新完、确认线上全是新版 → 最后才撤旧：腾讯云桶里的模型全部删干净、不留，老模型 CDN 下线，旧的东西清理掉。用户已授权 agent 去删，不用再问。

**Why:** 每次更新都全量下载一两百兆，用户认为"肯定不对"；本机模型走自己的 CDN 是最大的流量费来源，也会被刷。
**How to apply:** 动手前开分支；每件事做完按 [[acceptance-end-to-end]] 在两台机器上验。相关：[[speakmore-release-on-cos]]、[[speakmore-model-mirror]]、[[speakmore-cloud-billing]]、[[speakmore-download-stats]]、[[cloud-changes-user-runs]]。

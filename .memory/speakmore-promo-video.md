## 用户的要求（原话）

- 发布会式，不讲故事："像产品发布会那样，从功能入手，重点介绍产品的 feature"，"配合流畅的转场和画面切换"。
- 观感："冷静、克制、高级"，"要有一种很强的震撼感，但又不能太浮夸"；"发挥出你极高的审美，把这个视频当成一个真正的大厂产品宣发"。
- **字幕必须书面语**："像写书一样，用非常正式、非常书面的语言去表达"，口语化的主谓宾短句"像小学生写作文一样，这坚决不行"。（开场里的口述原话本来就是口语，那是被整理的对象，不算。）
- 不用合成人声："你千万不要用那种语音合成的声音去讲整个视频，这是非常 low 的东西"。全片靠字幕和画面，开场的说话过程也只用字幕表现。
- 成本紧跟功能："对于这些用户来说最关心的就是多少钱"；不讲架构："在产品宣发会里不要讲那么复杂的技术"；嫌第一版构思"太冗长"，节奏要快。
- 背景要有东西："背景不要纯黑"；用户提议用 Mac 桌面，并且"底下的应用栏没有嘛，纯背景咋知道是mac的桌面"——要有程序坞和菜单栏。
- 口述字幕"可以加速的，不用拘束在原速，表达出意思就好"。
- 声音："关于音效到时候你自己看着发挥，音乐不用担心，音乐加上之后感觉就上来了"（没说谁来找配乐，到时再问）。
- 横版为主、再出竖版；只做中文。
- 10-15 改成直接做、边看边调，不再先交字幕稿："做出来之后再边看边调"，"小步快跑"。字幕再强调一次："像产品宣发布会一样，简洁、干练，用最少的语言表达出最丰满的语义"。
- 不要人的主体（10-15 看完第 2 章后）："尽量不要出现'我'、'你'、'他'这样的词，减少人的这种感觉，不要出现人的主体性"，"作者为他……这种就很奇怪"。字幕只陈述事实，不写"作者""用户""你"；演示里被整理的口述原话不算。
- 之后一口气做完整片再给用户看（10-15）："你一下子全部连着做完吧……到时咱们直接看整篇，再根据整篇去调，就不用一段段找我确认了"。
- 官网和开源页面要出现："视频里和内容重要出现这个产品的官网和开源页面,也算是很重要的内容之一"——要有官网页面和 GitHub 仓库页面的画面，不只是落款里一行网址。
- 简洁易用要单独讲（10-15 追加）："speakmore不用语音转写模型,最干净,最方便,一个key->直接用"；用户看到很多同类"会先下载一个语音小模型+转给api润色,小模型的变量太大,工程环境很麻烦,对用户不友好"。

## 分章（横版约 75 秒；竖版约 50 秒，只留开场、来历、一把密钥、成本、两种装法、落款）

1. 开场 0–8s：已做，见下。
2. 来历：Typeless 是用过最好的语音输入，用户自己付过 $144/年；用 REA 拆开看（闪三四篇真实逆向笔记的标题，用户同意加）；从零重写，只留听写。REA 2026-10-15 是 263,675 星、66,308 fork，渲染当天重取。Typeless 只出现名字，不放它的标志和界面；说法和 README 一致（从零重写，不含它的代码和密钥）。
3. 怎么用：按、说、再按；任何能粘贴的地方；约 2 秒；三种整理快速切（去口癖、改口留最后一次、列举成条目）。
4. 一把密钥（10-15 新加）：不下载语音模型，不配运行环境；录音连同提示一次交给大模型，听写和整理一步完成；填一把 Gemini 或 OpenAI 的密钥就能用。代码已核实：`src/server/providers/gemini.mjs:65`、`openai.mjs:79` 直接把录音发给模型，仓库里没有本地语音模型、没有模型下载（README 的"One call, finished text"同一说法）。分寸：只说 SpeakMore 自己不需要什么，不点名、不评价别家；不画流程图（用户不让讲架构）。
5. 成本：紧跟上一章，讲的就是这把密钥花多少钱。单次 $0.0003、月均约 $1、免费额度内 $0；和 $144/年并排。
6. 两种装法：安装包（Apple 芯片、Intel 同等，经 Apple 公证）和命令行一行装好。
7. 隐私与开源：无需账号、没有中间服务器、记录只在本机、MIT。"直连模型"在第 4 章讲过，这里换隐私的角度，字幕别重复。
8. 落款：印章再盖一次，网址，"本片由 kineto 制作"。

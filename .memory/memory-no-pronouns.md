记忆里不用人称代词，每句话的主体写明：项目主人写"用户"，AI 这边写"agent"，用户和 agent 一起或项目自己这一方按意思写"本项目""SpeakMore"，外部贡献者写名字（如"贡献者 Kyle"）。"用户"只指项目主人；SpeakMore 的终端用户写"使用者"或"App 使用者"，免得同一句里两个"用户"分不清。引号里的原话一字不改，引导语照样写明是谁的原话。

**Why:** 2026-11-04 用户说"记忆里的描述都需要改一下，不要用你我他这种代词，指代不明确"。记忆是给以后的会话读的，换个会话"他""我"指谁就要靠猜。当天把 60 多个文件、约 700 处代词按这个规则改了一遍。

**How to apply:** 新写或更新记忆（包括 MEMORY.md 的索引行和 description）时照这个写；"其他、其它、他人"不是代词，不用改。相关：[[user-action-requests-plain-steps]]、[[decisions-as-options]]。

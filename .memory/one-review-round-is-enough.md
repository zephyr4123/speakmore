对抗性审查（派独立的 agent 找茬）做一轮就够：拿到结论、逐条核实、改完就收，不再派第二轮去审修复和后续改动。2026-10-14 用户原话："不用审第二轮了，审一次就够了"。

**Why:** AGENTS.md 写的是"审到连续一轮再无实质新发现为止"，用户嫌多审的那几轮花时间、收益小；这条是用户对那条规矩的具体放宽。

分步实施的大活也一样：中途不审，全部步骤做完再统一审一轮，覆盖所有步骤。2026-10-21 热键重构做到第 5 步时 agent 派了只审第 5 步的 workflow，用户先问"前面四步都不审查了吗"，又说"别中途审，全部做完了再一起审，这样子的审查才有意义"。审的时候用 workflow 多路并行（不是一个子 agent），数量控制在十个上下（[[workflow-agent-budget]]）。

**How to apply:** 一个功能做完派一轮审查即可；分步的活等最后一步做完再审，审查范围是全部步骤的改动；之后的修复、追加的小功能靠测试和真机验证把关，不再自动派审查 agent。用户点名要再审时才派。和 [[dont-rerun-tests-without-changes]] 一样，是在"验证到位"和"不重复花时间"之间用户选的平衡点。

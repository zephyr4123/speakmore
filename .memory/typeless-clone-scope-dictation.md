仿刻范围已定：只做语音转写这一个功能。用户 2026-10-13 的原话："我们只仿刻语音转写的这一个，因为我就用过这个"。用户的用法是按一次 fn、说话、再按一次，结果落到选中的输入位置，并存进历史记录。

**Why:** 逆向 Typeless 的目的是学习，之后仿刻一个服务端自建的玩具。翻译模式和"问任何事"用户没用过。

**How to apply:** 仿刻的设计、文档和后续抓包都只围绕"单击听写 → 插入到焦点输入框 → 存历史"。翻译、问任何事、云同步、企业策略不做，也不用再为它们补逆向。同一天 agent 告诉用户：就这个范围而言客户端逆向已经够开工，逆向不出来的是服务端的识别和清洗（模型、提示词），那部分要自己设计；这个"够开工"是 agent 的判断。相关：[[rea-is-the-primary-tool]]、[[user-action-requests-plain-steps]]。

**更新（2026-10-22）：** 用户说产品定位是"语音转写，以及之后的同声传译和翻译"，所以翻译不再算不做，是之后的方向（还没开工，没有设计）。会议纪要、嵌进腾讯会议或钉钉这类请求不做：issue #15 要会议纪要，照用户的话委婉回复定位后以 not planned 关掉。类似的功能请求照这个口径回。

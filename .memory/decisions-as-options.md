2026-10-21 过热键的 D1–D13 时，agent 先用文字讲 D1、问用户定不定，用户说："你可以把这 1、2、3 个需要我拍板的东西做成选项，然后我来选。就算我有什么小想法，也会直接在选项里面跟你说。"之后三批、每批四条，用户很快选完，有不同意见的直接写在"其他"里（D4 还附了 Typeless 的截图）。

**Why:** 一条条用文字来回问太慢；选项能让用户一眼比较、快速点选，补充意见也有地方写。

**How to apply:**
- 要用户拍板的事超过一两件时，用 AskUserQuestion 做成选项，一次最多四条，分批发。
- 每条写清楚是什么场景、各选项的代价；推荐的放第一个、标"（推荐）"；和既定原则冲突的选项（比如"老用户无感"、AGENTS.md 红线）在描述里写明。
- 用户在"其他"里写的是真实意见，常和推荐不同，照用户说的改，并把连带要改的地方一起改掉。相关：[[user-action-requests-plain-steps]]、[[speakmore-hotkey-any-key]]。
- 用户只说"先看看是干啥的、看了再决定"时，只讲清楚它做了什么，不带审查结论、不弹选项。10-30 看 PR #22 时 agent 讲完直接弹了选项，用户打断说："不着急，先告诉我他在干啥"。等用户听懂了、开口要决定了再给选项。
